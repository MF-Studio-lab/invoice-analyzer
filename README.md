# 載具電子發票分析系統

一個簡單易用的電子發票分析工具，讓您可以輕鬆上傳財政部電子發票 CSV 檔案，並以圖表和表格形式查看消費記錄。

## 功能特色

- 📤 **CSV 檔案上傳**：支援拖放或點擊上傳財政部電子發票 CSV 檔案
- 📊 **數據解析**：自動解析消費金額、日期、品項與商店名稱
- 📈 **圖表視覺化**：
  - 每月消費走勢圖（折線圖）
  - 消費類別比例（圓餅圖）
- 📋 **清單顯示**：表格顯示所有發票明細
- 🔍 **搜尋功能**：快速搜尋商店、品項或發票號碼
- 📥 **匯出功能**：將篩選後的資料匯出為 CSV 檔案
- 🌙 **深色模式**：現代化的深色主題設計
- 📱 **響應式設計**：完美支援手機與電腦瀏覽

## 技術棧

- **前端框架**：原生 HTML/JavaScript
- **樣式框架**：Tailwind CSS (CDN)
- **圖表庫**：Chart.js
- **CSV 解析**：PapaParse
- **部署平台**：GitHub Pages

## 使用方式

### 1. 上傳發票檔案

- 點擊上傳區域或拖放 CSV 檔案到頁面上
- 系統會自動解析檔案內容

### 2. 查看統計資料

- 總消費金額
- 發票總數
- 平均消費金額
- 商店數量

### 3. 分析圖表

- **每月消費走勢**：查看每月的消費變化趨勢
- **消費類別比例**：了解各商店的消費佔比

### 4. 搜尋與篩選

- 在搜尋框輸入關鍵字
- 系統會即時篩選符合條件的記錄

### 5. 匯出資料

- 點擊「匯出 CSV」按鈕
- 將當前篩選結果下載為 CSV 檔案

## CSV 檔案格式

系統支援多種欄位名稱，會自動識別以下欄位：

| 功能 | 支援的欄位名稱 |
|------|--------------|
| 金額 | 消費金額、金額、Amount、amount、總金額、Total |
| 日期 | 日期、Date、date、發票日期、InvoiceDate、時間 |
| 品項 | 品項、品名、Item、item、商品名稱、Product、Description |
| 商店 | 商店名稱、店名、Store、store、賣方名稱、Seller、商家 |
| 發票號碼 | 發票號碼、InvoiceNumber、invoice、發票號、No |

### 範例 CSV 格式

```csv
日期,發票號碼,商店名稱,品項,金額
2026-01-15,AB12345678,7-ELEVEN,咖啡,65
2026-01-16,CD23456789,全家便利商店,便當,89
2026-01-17,EF34567890,星巴克,拿鐵,150
```
