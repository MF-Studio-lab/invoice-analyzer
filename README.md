## 使用方式

### 1. 如何取得發票檔案

首次使用時，系統會自動顯示操作導覽。您也可以隨時點擊右上角的「❓ 如何取得發票」按鈕查看詳細說明。

**步驟：**

1. 登入[財政部電子發票整合服務平台](https://einvoice.nat.gov.tw/)
2. 進入「手機條碼專區」 > 「發票查詢/列印/下載」
3. 設定日期區間並查詢（建議以月為單位）
4. 捲動至頁面最下方點選「下載 CSV」

**💡 多月份提示：** 若您需要分析多個月份的發票，請重複上述步驟，分別下載各月份的 CSV 檔案。然後將所有檔案一起拖入本網站，系統會自動整合並剔除重複的發票。

### 2. 上傳發票檔案

- 點擊上傳區域或拖放 CSV 檔案到頁面上
- 支援一次選取多個檔案
- 系統會顯示處理進度
- 自動剔除重複的發票記錄

### 3. 查看統計資料

- 總消費金額
- 發票總數
- 平均消費金額
- 商店數量
- 日期範圍

### 4. 分析圖表

- **每月消費走勢**：查看每月的消費變化趨勢
- **消費類別比例**：了解各商店的消費佔比

### 5. 搜尋與篩選

- 在搜尋框輸入關鍵字
- 系統會即時篩選符合條件的記錄

### 6. 匯出資料

- 點擊「📥 匯出 CSV」按鈕
- 將當前篩選結果下載為 CSV 檔案

### 7. 清除資料

- 點擊右上角的「🗑️ 清除資料」按鈕
- 確認後會清除所有發票資料和 localStorage
